# Demo script (60–90 seconds)

One scripted lead, intake to booked appointment. No cuts.

1. **Open the chat widget.** "Pretend it's 9 PM and a homeowner's AC just died."
2. **Type:** "Hi, my AC stopped working, it's getting hot in here."
3. **Agent asks** for name + address area (intake). Give them.
4. **Agent asks** 2 qualifying questions (own or rent? how urgent?). Answer.
5. **Agent:** "You're all set — I can have a tech out tomorrow between 10 and 12. Does that work?"
6. **Type:** "Yes."
7. **Agent confirms** the booking, repeats the details back — **without re-asking anything**.
8. **Cut to Evolus workspace:** the lead summary + booking is there.

The line that sells it: *"Every step of that conversation was a separate agent call.
None of them re-asked a single question — because they all share one memory."*
