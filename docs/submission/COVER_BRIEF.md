# Cover image brief

Paint a quiet nighttime kitchen, phone in a homeowner’s hand, screen showing a short plain-text chat that has just confirmed a next-morning AC visit, with a dark storefront window or a closed shop sign soft in the background so the after-hours problem is obvious without a logo. Mood is calm and capable: warm practical light from the phone, no neon, no robots, no circuit-board sci-fi, no stock-photo handshake. Suggested text overlay, set in a plain sans serif and kept to two lines: “Operator Intake Agent” and “After-hours leads, booked before morning.” Leave AMD and Evolus wordmarks off the image unless the designer is placing official brand assets the team already has permission to use. This brief is for a human designer; do not drop a generated image into the repo from this file.
